## D. 복제/재고 등록 모달 정비 (미커밋) — `src/routes/cms/products/+page.server.ts`

### D-1. 메타데이터 `loadProductsMetadata`
- 신규 `categoryComboItemsByCategory`: 카테고리 키(`code_mapping_groups.default_category`) → 그 카테고리의
  코드조합 전체(협력사 여부 무관). 기존 `partnerComboItems` 출력은 동일 유지(조합 항목 조회를
  partner 그룹+카테고리 그룹 합집합 1회로 통합).
- 각 조합에 `has_parent_seq`(순번1 있는 2단 조합 여부)·`duplicate_parent_code`(1단 조합이면서 이번
  연월로 동일 부모 코드품번 상품이 이미 존재) 플래그 추가. 모듈 함수 `currentYearMonthKey`
  (`none`→`nodate`, `ymd`→YYMMDD, 그 외 YYMM, UTC = DB `NOW()`).
- 60초 인메모리 캐시 유지, 복제 성공 시 `metadataCache = null`로 즉시 무효화.

### D-2. `cloneProduct` — 새 상품 복제(new_product)
- **삭제된 로직**: 원본의 `code_series`를 그대로 물려받는 "자동 생성(autoCode)" 분기 전체
  (동일 부모 코드품번 상품을 만들던 원인), `autoCode` 변수, 1단 조합 다수 복제 허용.
- **정책 집행(서버가 최종)**: 코드조합(`partner_combo_row_id`) 미선택 400 / 자동 생성 모드에서 원본
  카테고리 소속이 아닌 조합 400 / 존재하지 않는 조합 400 / 1단 조합이 같은 category_code+year_month의
  1단 부모(`code_series` jsonb contains, deleted_at null)와 동일하면 400.
- 등록 수량 개념 제거 — 항상 1개(`count`는 무시).
- **복제 범위 확대**(장치정보·이력 제외 전체): 원본 select에 `components`, `allowed_period/method/
  pickup_ids`, `shipping_round_trip/delivery/return` 추가 → INSERT 포함. 옵션상품 연결은
  `get_product_option_links` → `upsert_product_option_links`. 이미지는 신규 `copyProductImages`로
  Storage(`product-images`)의 large_/thumb_ 파일을 새 상품 폴더로 실제 복사(외부 URL은 그대로,
  large 복사 실패분은 제외+경고) — 원본과 파일 공유 시 한쪽 삭제가 다른 쪽을 깨뜨리는 문제 방지.
  새 상품은 여전히 `is_active=false`, 재고(자식) 미생성.

### D-3. `cloneProduct` — 동일 상품 재고 추가(add_inventory)
- `count`는 1~50으로 clamp(정수).
- **순번 상한 사전 차단**: 부모 `code_series.max_sequence`와 카운터(`product_child_sequences_by_parent`
  또는 1단은 `product_code_sequences[category_code+year_month]`)의 `next_seq`로
  `remaining = max − (next_seq − 1)` 계산, `remaining < count`면 재고를 하나도 만들지 않고 400.
- 만든 뒤 `max_sequence_exceeded`가 나면(레이스) 방금 만든 재고를 소프트삭제(`is_active=false`,
  `deleted_at`) 후 400 — 품번 없는 대여가능 재고가 남던 결함 해소.
