### 4-1. 상태 흐름 (CMS 삭제·본인 탈퇴 공통)

```
정상(active)
  ├─ 삭제 요청(본인 탈퇴 신청 | CMS 관리자 삭제) ── 차단 조건 통과 시에만
  ▼
삭제 유예(30일)  ── 본인 탈퇴: 같은 이메일로 재로그인하면 자동 복구(현행 유지)

  ▼ (30일 경과, 매일 01:00 UTC 크론)
익명 전환(anonymized)  ── 개인정보 제거, 거래 기록은 계정 ID에 익명으로 연결해 보존
  │   ├─ 이메일 재가입 제한: 익명 전환일부터 3개월(이메일 해시로만 보관)

```

### 4-2. 삭제 차단 조건 (공통 함수 `check_account_deletable`)

본인 탈퇴와 CMS 삭제가 **같은 판정 함수**를 쓴다(이중 구현 방지). 하나라도 해당하면 요청 자체를 거절하고 사유 목록을 돌려준다.

| 사유 | 판정 |
|---|---|
| 진행 중 대여 | 예약 상태 hold·confirmed·shipped·in_use·return_requested (현행) |
| 반납 후 미결 | returned 이면서 검수 상태가 대기·이슈, 파손 신고(damage_claimed), 추가 청구 미정산 |
| 취소 요청 처리 대기 | `cancel_requested_at` 있는 계약완료 예약 |
| 활성 구독 | `user_subscriptions.status='active'` |
| 환불 진행 중 | 환불 대기 상태 결제 |

- CMS 화면은 차단 사유를 목록으로 보여준다(예: "진행 중 대여 2건"). 본인 탈퇴 화면은 기존 안내문에 사유를 덧붙인다.
- 포인트·쿠폰은 약관대로 소멸(차단 사유 아님). 소멸 전 안내 문구는 기존 유지.

### 4-4. 기록 보호 장치

- `rental_reservations.user_id`·`orders.user_id`·`user_subscriptions.user_id`의 외래키를 **CASCADE → RESTRICT**로 변경(계정 물리 삭제 시 거래 기록이 함께 사라지지 않게). 영향: 테스트·정리 스크립트의 계정 삭제 순서 점검 필요.
- "삭제"는 익명 전환만 허용하고 계정(auth) 물리 삭제는 거래 기록이 없는 임시 계정(익명 방문자)으로 한정한다.

### 4-5. 관리대상 유지

- `soft_delete_customer`가 `blacklisted=false`로 풀던 동작을 **제거**한다(유예 중에도 관리대상 목록에 그대로 노출, '삭제 요청' 배지 표시).
- 익명 전환 시점에 `blacklisted=true` 계정이면 `managed_persons`(사전 등록 관리대상)에 이름·전화·이메일·생일·사유를 이관한다. 이후 같은 사람이 재가입하면 기존 대조 기능(Migration #707~#709)이 '미확인' 배지로 알려준다.
- ⚠️ 개인정보 보호 관점: 관리대상 식별정보를 법정 보존 기간 밖에서 보관하는 근거·기간을 처리방침에 명시해야 한다(법무 확인 6번).

### 4-5-1. 재가입 제한 (이메일)

- 신규 테이블 `signup_restrictions(email_hash, restricted_until, source_user_id, created_at)` — 이메일은 **소문자·공백 제거 후 해시(SHA-256 + 서버 비밀값)** 로만 저장.
- 익명 전환 시점에 `restricted_until = 익명 전환 시각 + 3개월` 생성(본인 탈퇴·CMS 삭제 동일).
- 가입 화면: 이메일 확인 단계에서 제한 중이면 "탈퇴한 이메일은 YYYY.MM.DD 이후 다시 가입할 수 있어요" 안내. 서버(가입 마무리 직전)도 같은 검사를 한 번 더 한다(화면 우회 방지).
- 유예 중(30일)은 제한이 아니라 복구 대상이므로 이 규칙과 무관.
- 휴대폰 번호: 현재 익명 전환 시 번호가 비워져 즉시 재사용 가능 — 번호도 제한할지는 6번.

### 구현 중 발견한 주의점
- **`banned_until='infinity'`는 사용 금지** — Auth 서버가 해당 계정 조회를 못 해 계정 삭제·조회가 깨진다(Stage 실측). 100년 후 날짜로 대체했다.

## 9. 약관·처리방침 개정 문구 초안 (법무 확인 후 CMS 정책관리에서 반영, 시행 30일 전 공지)

**이용약관(회원 탈퇴 조항에 추가)**
> 회원이 탈퇴하면 탈퇴일로부터 30일 동안 계정이 보관되며, 이 기간 안에 같은 계정으로 다시 로그인하면 탈퇴가 취소됩니다. 30일이 지나면 개인정보는 익명 처리되어 복구할 수 없습니다. 탈퇴(익명 처리)일로부터 3개월 동안은 같은 이메일로 다시 가입할 수 없습니다. 진행 중인 대여, 반납 후 검수가 끝나지 않은 대여, 이용 중인 구독이 있으면 정리가 끝난 뒤 탈퇴할 수 있습니다. 관리자는 회원이 약관을 위반하는 등 정당한 사유가 있을 때 회원 계정을 삭제할 수 있으며, 이 경우에도 같은 유예·익명 처리 절차를 따릅니다.

**개인정보처리방침(보관 기간·항목에 추가)**
> - 재가입 제한 확인 정보: 탈퇴한 이메일의 해시값(복원할 수 없는 형태) — 익명 처리일로부터 3개월
> - 이용 제한(관리대상) 고객 식별 정보: 서비스 이용 제한 이력이 있는 경우 재가입 시 확인하기 위해 이름·연락처·이메일·생년월일·사유 — 보관 근거·기간은 법무 확인 후 기재
> - 작성한 후기·댓글: 탈퇴 후에도 내용은 유지되며 작성자 표시는 익명으로 바뀝니다(직접 삭제한 글은 제외)
